# 智慧停车收费系统知识库总览

本目录用于沉淀停车收费平台资料，后续作为内部检索、AI 问答、客户演示材料生成和版本维护的统一知识入口。

## 知识库分层

| 层级 | 文件 | 用途 | 对外程度 |
| --- | --- | --- | --- |
| 用户手册 | `../停车收费系统用户手册.md`、`../index.html` | 面向客户演示，描述已确认的页面功能和操作方式。 | 可对外 |
| 页面知识库 | `页面知识库.md` | 面向内部检索，记录每个后台页面的入口、标题、按钮、筛选项、表格字段和实测来源。 | 内部为主 |
| 业务规则库 | `业务规则库.md` | 只记录已确认业务规则、来源和待确认问题，避免把页面现象误写成规则。 | 内部为主 |
| 维护规范 | `维护规范.md` | 规定资料采集、版本归档、截图和 Git 提交流程。 | 内部 |

## 使用原则

1. 面向客户的内容写入用户手册，表达要简洁、确定、可演示。
2. 页面级事实写入页面知识库，保留入口、字段和按钮，方便后续检索。
3. 规则类内容必须写明来源和确认状态；没有确认的，放入“待确认”。
4. 截图、实测记录和版本记录要能互相追溯。
5. 不上传原始 Obsidian 资料目录，只上传整理后的交付物和必要的知识库文件。

## 后续推荐工作流

1. 先实测页面或整理已确认资料。
2. 更新页面知识库或业务规则库。
3. 将可对外表达的内容同步到用户手册。
4. 重新生成 `index.html`。
5. 归档版本并更新版本记录。
6. 精确暂存本次文件，提交并推送。
