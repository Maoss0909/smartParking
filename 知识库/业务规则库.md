# 业务规则库

本文件只记录已确认业务规则、确认来源和待确认问题。页面只显示入口或按钮但没有展示结果的内容，不直接写成规则。

## 规则状态

| 状态 | 含义 |
| --- | --- |
| 已确认 | 已有资料、截图或测试环境实测能够支撑，可以写入用户手册。 |
| 页面可见 | 页面存在入口、按钮或字段，但未完整确认生效机制。 |
| 待确认 | 需要用户、业务方、测试环境闭环或代码/API 佐证。 |

## 待确认问题

1. PDA 收费终端登录、泊位操作、补录、追缴和消息通知的完整流程。
2. 微信小程序车主端停车缴费、会员、优惠券、发票、申请驶离的完整流程。
3. 封闭车场相机、道闸、费显的真实联动流程和异常处理流程。
4. 退款、作废、欠费清除、补缴欠费、发送短信等高影响操作的业务审批和权限边界。
5. 支付对账差异处理、子商户对账、手续费和入账净额的财务口径。
6. 系统配置项保存后的生效时间、影响范围和回滚方式。

## 更新要求

- 每次新增规则，都必须写明来源和状态。
- 规则不确定时，先放到“待确认问题”，不要写入“已确认规则”。
- 如果规则已同步到用户手册，在备注中写明对应版本。
