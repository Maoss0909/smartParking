# 用户手册索引

本文件用于说明知识库与客户演示材料之间的关系。

## 当前交付物

| 文件 | 说明 |
| --- | --- |
| `../停车收费系统用户手册.md` | 当前工作版用户手册，面向客户和内部维护人员。 |
| `../index.html` | 由用户手册生成的 HTML 演示页，可用于浏览器演示和搜索。 |
| `../版本管理/用户手册/V1.1/停车收费系统用户手册.md` | V1.1 归档快照。 |
| `../版本管理/用户手册/版本记录.md` | 用户手册版本记录。 |

## 与知识库的关系

| 内容类型 | 主要维护位置 | 是否同步用户手册 |
| --- | --- | --- |
| 页面入口、按钮、字段、表格列 | `页面知识库.md` | 只同步客户需要理解的页面。 |
| 已确认业务规则 | `业务规则库.md` | 可以同步，但要用用户能理解的表达。 |
| 待确认问题 | `业务规则库.md` | 不同步到用户手册，除非需要写成“本版未覆盖范围”。 |
| 客户演示说明 | `../停车收费系统用户手册.md` | 是主要输出。 |
| HTML 样式和搜索体验 | `../index.html`、`../tools/build_manual_html.rb` | 由生成脚本维护。 |

## 后续同步规则

1. 页面知识库可以比用户手册更细，但用户手册必须更稳、更少内部噪音。
2. 用户手册新增内容前，优先检查业务规则库是否存在未确认项。
3. HTML 只从用户手册生成，不直接从页面知识库生成。
4. 客户演示时优先打开 `../index.html`。
