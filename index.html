1. 手册说明

1.1 适用对象

本手册面向停车收费管理平台的日常使用人员，包括平台管理员、停车运营人员、收费管理人员、客服处理人员、财务对账人员等。

1.2 系统定位

停车收费管理平台面向城市级及物业级停车管理场景，提供路侧停车与封闭车场一体化管理能力。系统品牌名可配置，现有资料中记录为“一九智慧停车 / 涵涵物业智慧停车”。

1.3 功能模块总览

模块说明
监控台平台首页，展示平台使用引导、关键经营指标、收入趋势、投诉/申诉和帮助入口。
停车中心车场、车位、收费规则、设备、故障、停车引导等停车基础业务管理。
订单中心停车订单、支付流水、退款记录、异常订单、超时订单、欠费订单、订单合并等订单相关页面。
运营中心营收统计、员工管理、客户管理、会员、优惠券、发票、白名单等运营页面。
系统中心商户配置、系统用户、系统日志、系统配置、系统工具等平台配置页面。
个人中心个人信息、下载中心、批量任务。
封闭车场顶部导航中存在“封闭车场”入口，当前截图集中未包含该模块页面，本手册不展开。
终端应用顶部导航中存在“停车驾驶舱”“下载中心”等入口；PDA 和小程序页面截图当前未包含在截图集中，本手册不展开终端端流程。

2. 登录后首页与导航

2.1 监控台

监控台是登录后的首页。页面显示顶部提供平台主导航，页面主体包含使用引导、费用概览、昨日收入概览、昨日收入分布、近七日趋势、微信投诉、异常申诉、公告和使用帮助等区域。

监控台上方的引导区展示平台初始化流程，包括“选择入驻方式”“配置收费规则”“配置路段及泊位”“添加收费员”“下载手持机 APK”。下方的数据区展示泊位数量、注册用户、支付金额、支付笔数、历史会员、当前会员、企业余额、短信余量和待支付等信息。收入图表区域用于查看昨日收入和近七日趋势；右侧帮助区域提供新手引导、接入准备、产品文档等入口。

3. 停车中心

停车中心是当前资料中内容最完整的模块，包含车场管理、车位管理、车场监管、车位监管、收费规则等核心功能。

3.1 车场管理

入口：停车中心 → 停车管理 → 车场管理

车场管理用于维护路侧或封闭停车路段的基础信息，包括新建、编辑、删除、数据导出、监管数据重置和路段图片维护。路段是系统管理停车业务的基础地理单元，一个路段下可以包含多个泊位。只有启用状态的路段，才能正常接收停车订单、设备上报和收费业务。

3.1.1 查询路段

  1. 进入“停车中心 → 停车管理 → 车场管理”。
  2. 在筛选区输入路段名称、路段编号、是否启用、收费规则等条件。
  3. 点击“查询”加载结果。
  4. 点击“重置”清空筛选条件。

3.1.2 新建路段

  1. 点击“新建路段”。
  2. 填写路段名称、是否启用、收费规则、路段模式、计费规则、停车类型、经纬度等信息。
  3. 在地图中选址，系统自动回填坐标，必要时可微调。
  4. 点击“保存”。

新建路段不会同步创建泊位。创建路段后，需要到“车位管理”单独添加泊位，也可以通过“批量任务”创建批量添加泊位任务。

3.1.3 编辑路段

  1. 在目标路段操作列点击“编辑”。
  2. 修改需要调整的字段。
  3. 点击“保存”。

注意：修改收费规则不影响已产生的在停订单，在停订单仍按订单创建时的收费规则计费。修改路段模式会影响在停订单，例如取消“地磁”后，该路段不再处理地磁上报数据，在停车辆只能手动驶离。

3.1.4 删除路段

  1. 在目标路段操作列点击“删除”。
  2. 阅读系统二次确认提示。
  3. 确认无误后点击确认删除。

删除路段不可逆，会同步删除该路段下所有泊位数据，泊位绑定的设备会自动变更为未绑定状态，并可能影响尚未驶出的订单。删除前建议先处理在停车辆并做好数据备份。

3.1.5 数据导出

  1. 点击“数据导出”。
  2. 在弹窗中选择注册时间范围。
  3. 点击“确定”，系统生成并下载 Excel 文件。

导出字段包括路段名称、路段编号、泊位数量、是否启用、路段模式、支付离场、收费规则、创建时间、所在省市、路段位置、路段坐标等。

3.1.6 重置监管数据

当某一路段的泊位统计数据异常时，可在操作列点击“重置”，重新计算监管中的泊位统计数据。

重置只修复监管看板上的统计结果，不改变设备实际状态。

3.1.7 维护路段图片

  1. 在操作列点击“图片”。
  2. 上传路段展示图片。
  3. 点击“保存”。

现有资料说明该图片可用于路段图片展示，例如车主小程序中的路段详情页。

3.1.8 路段模式说明

模式说明
PDA收费员手持终端录入，负责拍照识别车牌、打印停车小票、补录地磁漏检车辆。
地磁地磁设备自动检测车辆驶入和驶离时间。
巡检车批量录入车牌信息，可与地磁数据进行二次校验。
视频桩 / 路牙机 / 高位视频视频设备自动识别车牌。
地锁通过地锁升降控制车辆停放。

现有资料说明 PDA 一般为必备，常见组合包括 PDA + 地磁、PDA + 地磁 + 巡检车、PDA + 视频桩 / 路牙机 / 高位视频 / 地锁。

3.2 车场监管

入口：停车中心 → 停车管理 → 车场监管

车场监管用于汇总查看各路段的泊位动态数据，包括泊位总数、空闲泊位、占用泊位、停车数量、统计异常数和最后更新时间。

3.2.1 查询路段监管数据

  1. 进入“停车中心 → 停车管理 → 车场监管”。
  2. 在路段名称输入框中输入关键词。
  3. 点击“查询”。
  4. 点击“重置”清空筛选条件。

3.2.2 重置路段监管数据

当泊位统计数据与实际不符、停车数量与占用泊位不一致，或统计异常数大于 0 时，可在目标路段操作列点击“重置”。

字段关系：

字段说明
泊位总数该路段下绑定的泊位总数。
空闲泊位当前未被占用的泊位数量。
占用泊位当前被车辆占用的泊位数量。
停车数量当前在停车辆数。正常情况下与占用泊位接近。
统计异常数泊位状态与订单数据不一致的数量。

3.3 车位管理

入口：停车中心 → 停车管理 → 车位管理

车位管理用于维护各路段下的泊位档案，支持查询、新增、编辑、删除、批量迁移、批量驶出、批量删除、数据导出和查看设备上报数据。

3.3.1 查询泊位

  1. 进入“停车中心 → 停车管理 → 车位管理”。
  2. 输入或选择查询条件：路段名称、泊位编号、设备编号、当前状态、当前车牌。
  3. 点击“查询”查看结果。
  4. 点击“重置”清空条件。
  5. 点击“展开”或“收起”切换高级查询条件。

3.3.2 添加泊位

  1. 点击“添加泊位”。
  2. 选择路段。
  3. 输入泊位编号。
  4. 选择设备类型和设备编号。
  5. 点击“确定”保存。

泊位编号只支持字母、数字、-，长度不超过 50 字符。同一路段内不可重复，不同路段之间可以重复。

3.3.3 编辑泊位

  1. 在目标泊位操作列点击“编辑”。
  2. 修改泊位编号、设备类型或设备编号。
  3. 点击“确定”。

单个泊位编辑时不可修改所属路段。如需调整所属路段，使用批量迁移。

3.3.4 删除泊位

  1. 在目标泊位操作列点击“删除”。
  2. 在确认弹窗中点击“确定”。

如果该泊位存在在停订单，系统会拦截删除，并提示先驶出订单后再尝试删除。删除泊位不影响历史订单。

3.3.5 批量操作

勾选列表左侧复选框后，可进行批量迁移、批量驶出、批量删除。

批量操作说明
批量迁移将选中泊位迁移到另一个已创建路段。系统会校验目标路段是否存在泊位编号冲突。
批量驶出对选中的在停泊位执行批量驶出，以当前操作时间作为驶出时间结算订单。
批量删除删除选中的泊位。若存在在停订单，系统会拦截。

3.3.6 数据导出

  1. 点击“数据导出”。
  2. 选择需要导出的路段。
  3. 点击“确定”，系统下载 Excel 文件。

导出字段包括路段名称、泊位编号、设备编号、当前状态、当前车牌、创建时间。不支持按时间范围导出，也不支持自定义导出列。

3.3.7 查看设备上报数据

已绑定设备的泊位，设备编号列为蓝色链接。点击设备编号可查看该设备近期上报数据。

上报数据可用于排查设备是否正常工作、数据上报是否及时。

3.3.8 泊位状态

状态含义
空闲泊位无车。
车辆未录入泊位被占用，但未识别或未录入车牌。
车牌已录入泊位被占用，且车牌已识别录入。
未知状态设备长时间未上报、数据异常，或泊位未绑定设备。
未绑定设备添加泊位时未选择设备。

3.4 车位监管

入口：停车中心 → 停车管理 → 车位监管

车位监管以卡片形式展示泊位实时状态，支持按全部、在停、空闲三种状态切换，并可通过路段名称、泊位编号、设备编号筛选。

3.4.1 切换状态视图

点击页面顶部 Tab：

Tab说明
全部展示所有状态的泊位。
在停展示当前被车辆占用的泊位，包括已录入车牌和待录入。
空闲展示当前无车辆占用的泊位。

3.4.2 筛选查询

筛选条件包括路段名称、泊位编号、设备编号。输入条件后点击“查询”，点击“重置”恢复默认展示。

3.4.3 卡片颜色与状态

卡片颜色泊位状态卡片顶部内容说明
蓝色在停车牌号码泊位被占用，且系统已记录车牌。
橙色在停待录入泊位被占用，但车牌尚未录入，需要收费员通过 PDA 补录。
绿色空闲空闲泊位无车辆占用。
紫色未知未知状态系统无法判断实际状态，可能未绑定设备或设备长时间未上报。

车位监管卡片仅用于信息展示，当前资料说明不支持点击跳转或弹出详情。查询结果固定每页 10 条。

3.5 收费规则

入口：停车中心 → 收费管理 → 收费规则

收费规则用于维护平台停车计费策略。系统支持按天-时刻收费、按天-时长收费、时长收费三种规则类型，并支持规则校验和收费标准图片上传。

3.5.1 查询收费规则

  1. 进入“停车中心 → 收费管理 → 收费规则”。
  2. 在“规则名称”输入框输入关键词。
  3. 点击“查询”。
  4. 点击“重置”清空条件。

3.5.2 查看规则详情

点击规则列表左侧展开图标，可查看规则类型、收费日历、车辆类型折扣、小型车和大型车配置详情。

3.5.3 新增收费规则

  1. 点击“新增”。
  2. 填写规则名称、规则描述。
  3. 选择规则类型。
  4. 配置收费日历、秒数取舍、车辆类型折扣。
  5. 分别配置小型车和大型车收费参数。
  6. 点击“保存”。

新建规则时，规则版本由系统自动生成，初始版本为 v1.0。

3.5.4 编辑和删除收费规则

在目标规则操作列点击“编辑”可修改配置。编辑保存后，规则版本自动递增，例如 v1.0 变为 v2.0。

在目标规则操作列点击“删除”可删除规则。已被路段使用的收费规则不允许直接删除，系统会提示先更改路段所用收费规则。

3.5.5 规则校验

  1. 在目标规则操作列点击“校验”。
  2. 输入驶入时间、驶出时间、停车次数、车辆类型，选择是否启用收费日历。
  3. 点击“计算”。
  4. 查看停车总时长、本次计费时长、本次计费金额和费用明细。

规则校验用于在规则投入使用前模拟计费结果，确认配置是否符合预期。

3.5.6 上传收费标准图片

  1. 在目标规则操作列点击“图片”。
  2. 上传用于公示的收费规则图片。
  3. 点击“保存”。

上传后的收费标准图片用于车主小程序或公众号中的收费标准公示。

3.5.7 规则类型选择

规则类型适用场景特点
按天-时刻收费需要分时段差异化定价的路段或车场。以自然天为周期，按时刻区间划分不同时段。
按天-时长收费需要按天统计并设置时长上限、阶梯费率的场景。以天为计费周期，支持按天或按 24 小时定义一天。
时长收费按实际连续停放时长计费的路侧停车场景。按驶入到驶出的总时长连续计费，支持限制模式和限制金额。

3.5.8 车辆类型折扣

车辆类型折扣支持以下方式：

折扣方式说明
固定值折扣单笔订单按固定金额减免。
百分比折扣单笔订单按原费用的百分比收取。
免费时长延长在规则免费时长基础上延长免费时间。
停车时长减免减免参与计费的停车时长，仅时长收费模式支持。

3.5.9 收费规则注意事项

  1. 规则创建后仍可在三种类型之间切换，保存后版本自动递增。
  2. 小型车和大型车配置独立维护。
  3. 单次限额中，-1.00 表示无限制。
  4. 启用收费日历后，系统会结合收费日历中配置的免费日期进行减免。
  5. 已被路段使用的收费规则不可直接删除。

3.6 收费日历

入口：停车中心 → 收费管理 → 收费日历

收费日历用于维护特殊日期或免费日期类配置。页面显示提供日历视图和列表视图两种查看方式；列表视图中可以创建日历记录、编辑免费日期，也可以通过“批量添加”一次性维护多条日期配置。
